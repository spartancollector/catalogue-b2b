# Catalogue B2B Spartan Collector

Site du catalogue B2B, consultable en ligne, avec prix et stock modifiables directement sur GitHub.

## Comment modifier un prix ou un produit

1. Ouvre le fichier `products.json` sur GitHub
2. Clique sur l'icône crayon (en haut à droite du fichier) pour éditer
3. Modifie la valeur voulue (prix, stock "in"/"out", nom, photo...)
4. Descends en bas de page, clique "Commit changes"
5. Le site se met à jour automatiquement en 1-2 minutes
